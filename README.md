# wxsop

本仓库用于维护成长智远短周期活动公众号的标准流程与输入模板。

## 文件说明

- `SOP.md`：正式维护中的主文件。
- `Activity-Input.md`：活动资料输入模板。
- `CHANGELOG.md`：版本更新记录。

## 使用方式

当用户提出：

> 请按照 GitHub 中 wxsop 最新 SOP 执行

AI 应按以下顺序处理：

1. 读取 `SOP.md`
2. 若缺少活动资料，读取 `Activity-Input.md` 的输入要求并向用户收集
3. 按照 SOP 连续执行，不得跳步
4. 完成公众号文章、切片规划与图片生成

## 约定

- `SOP.md` 为唯一正式入口文件。
- `Activity-Input.md` 仅用于收集活动资料。
- `CHANGELOG.md` 仅用于记录更新。
